<div class="dsom-section">
  <h2>How to use this guide</h2>
</div>

<div class="dsom-steps">
  <p><strong>1. Choose a chapter</strong><br>Use the path cards above or the navigation sidebar. Each chapter has an overview and a list of guides.</p>
  <p><strong>2. Check the requirements</strong><br>Read the requirements before running a script. Pay attention to sudo, package, device, and version requirements.</p>
  <p><strong>3. Follow the guide</strong><br>Use the copy-paste installation snippets, then the usage and verification steps. Test backups and restores before relying on them.</p>
</div>

<div class="dsom-note">
  <strong>Safety note:</strong> Several guides change system settings, install software, mount shares, or process data in place. Review the script, keep backups, and do not run destructive commands on a device you cannot afford to lose. The guides describe intended behavior; they do not replace testing on your own hardware.
</div>
