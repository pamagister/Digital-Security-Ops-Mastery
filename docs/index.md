<div class="dsom-section">
  <h2>How to use this guide</h2>
</div>

<ul class="dsom-steps">
  <li><strong>1. Choose a chapter</strong>Use the path cards above or the navigation sidebar. Each chapter has an overview and a list of guides.</li>
  <li><strong>2. Check the requirements</strong>Read the requirements before running a script. Pay attention to sudo, package, device, and version requirements.</li>
  <li><strong>3. Follow the guide</strong>Use the copy-paste installation snippets, then the usage and verification steps. Test backups and restores before relying on them.</li>
</ul>

<div class="dsom-note">
  <strong>Safety note:</strong> Several guides change system settings, install software, mount shares, or process data in place. Review the script, keep backups, and do not run destructive commands on a device you cannot afford to lose. The guides describe intended behavior; they do not replace testing on your own hardware.
</div>
