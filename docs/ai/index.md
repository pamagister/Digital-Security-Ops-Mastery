## 🧭 What to expect

- **OpenCode needs a model provider.** It can use built-in free models, OpenRouter, Kilo AI, local models, or other OpenAI-compatible providers. Free availability and privacy conditions change.
- **Agents can act on your machine.** Grant only the permissions you need, work in dedicated directories, and review proposed commands.
- **Free models may log requests.** Do not submit passwords, API keys, confidential documents, or proprietary source code unless the provider's terms allow it.
- **Model data is volatile.** Benchmark values, prices, and free model IDs change frequently. Verify them before relying on them.

## 🚀 Start here

1. Read [Agentic AI & OpenCode](agentic-opencode.md) for installation and provider setup.
2. Read [Coding & agentic models](coding-agentic-models.md) before choosing a model.
3. Use the [OpenCode template](opencode-template.jsonc) as a starting point, then replace the generated catalog when needed.

The template's model list is generated by `update_model_catalog.py`. Run it with `--verify` to check whether the catalog still matches the current sources without modifying the template. Do not use `--skip-benchmarks` for a full comparison, because benchmark columns would be missing.
