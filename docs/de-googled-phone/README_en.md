# Setting up a de-Googled phone

An alternative Android operating system can reduce reliance on Google services, but it is not automatically more secure or completely Google-free. Before switching, check device support, security updates, required apps, and the official installation instructions. Unlocking the bootloader and flashing a ROM can erase data or make a device unusable.

## Operating systems
- GrapheneOS: https://grapheneos.org/ (supports specific devices; check the current device list and installation instructions)
- CalyxOS: https://calyxos.org/ (check device support and project status before installation)
- LineageOS: https://lineageos.org/ (broad but device-dependent support; security updates and device status vary)

The operating systems differ in security model, Google services, and supported devices. Follow only the official instructions for your exact device model and back up important data first.
Open-source apps are not automatically secure: check the publisher, source, permissions, and update status.

## Recommended apps
### App Stores
- ![app_image](../_static/ico/fdroid.ico) **[F-Droid](https://f-droid.org/)**: The app store that respects freedom and privacy
- ![app_image](../_static/ico/aurora.ico) **[Aurora Store](https://f-droid.org/packages/com.aurora.store/)**: An unofficial client for Google Play. Depending on how it is used, it may involve Google accounts or anonymous sessions; check its source, permissions, and privacy implications.

### Communication
- ![app_image](../_static/ico/k9mail.ico) **[K-9 Mail](https://f-droid.org/packages/com.fsck.k9/)**: Open-source email client.
- ![app_image](../_static/ico/conversations.ico) **[Conversations](https://f-droid.org/de/packages/eu.siacs.conversations/)**: An encrypted, user friendly XMPP instant messaging client optimized for mobile.

### Synchronization
- ![app_image](../_static/ico/nextcloud.ico) **[Nextcloud](https://f-droid.org/de/packages/com.nextcloud.client/)**: Client for synchronizing files and automatic uploads. Contacts, calendars, and tasks are usually synchronized through DAVx⁵ using CardDAV/CalDAV.
- ![app_image](../_static/ico/acalendar.ico) **[aCalendar](https://acalendar.tapirapps.de/en/support/home)**: Nice calendar display and widget, better handling than the standard calendar
- ![app_image](../_static/ico/nextcloudnotes.ico) **[Nextcloud Notes](https://f-droid.org/de/packages/it.niedermann.owncloud.notes/)**: View and edit notes on Nextcloud
- ![app_image](../_static/ico/opentasks.ico) **[OpenTasks](https://f-droid.org/de/packages/org.dmfs.tasks/)**: A task manager app, allowing you to categorize your todo list by urgency, state, timeframe etc.
- ![app_image](../_static/ico/davx5.ico) **[DAVx⁵](https://f-droid.org/de/packages/at.bitfire.davdroid/)**: DAVx⁵ is a CalDAV/CardDAV management and synchronization app for Android that integrates seamlessly with calendar and contacts apps.

### Productivity
- ![app_image](../_static/ico/aegis.ico) **[Aegis Authenticator](https://f-droid.org/de/packages/com.beemdevelopment.aegis/)**: Free, secure and open source 2FA app to manage tokens for your online services.
- ![app_image](../_static/ico/keepassdx.ico) **[KeePassDX](https://f-droid.org/de/packages/com.kunzisoft.keepass.libre/)**: Secure and open source password manager compatible with KeePass files. 
- ![app_image](../_static/ico/osmand.ico) **[OsmAnd](https://f-droid.org/packages/net.osmand.plus/)**: Map and navigation app with offline maps based on OpenStreetMap.
- ![app_image](../_static/ico/openoffice.ico) **[OpenDocument Reader](https://f-droid.org/de/packages/at.tomtasche.reader/)**: Open OpenDocument files on the go; editing features depend on the app version.
- ![app_image](../_static/ico/collabora.ico) **[Collabora Office](https://www.collaboraoffice.com/collabora-office-android-ios/)**: Open and edit documents, for example from Nextcloud. The office app is based on LibreOffice.
